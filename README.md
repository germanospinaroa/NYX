# NYX

NYX es una plataforma de Relationship Intelligence para organizar, recordar y activar mejores relaciones y conversaciones.

Estado: early development.

Principio central: mejores relaciones y mejores conversaciones, no más mensajes.

Consulta [PRODUCT.md](docs/PRODUCT.md), [MVP.md](docs/MVP.md) y [ARCHITECTURE.md](docs/ARCHITECTURE.md) para la definición actual.
